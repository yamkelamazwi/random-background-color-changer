# Random Background Color Changer

A beginner-friendly JavaScript project that generates a random dark background color every time the user clicks a button. The selected hex code is displayed on the page so users can see exactly which color was applied.

## Features

- Generate a random dark color from a predefined array
- Update the page background dynamically
- Display the current hex color code
- Smooth background color transition
- Built with HTML, CSS, and JavaScript

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## How It Works

1. A collection of dark hex colors is stored in an array.
2. A random index is generated using `Math.random()`.
3. When the button is clicked:
   - A random color is selected from the array.
   - The page background updates to the selected color.
   - The corresponding hex code is displayed on the screen.
